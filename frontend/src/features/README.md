# Frontend Feature Modules

This directory contains domain feature vertical slices for upcoming implementation phases:
- `session-wizard/`: Guided multi-step test workflow (Phase 1).
- `capture-gating/`: Card alignment, live stream pre-validation, and capture upload (Phase 2).
- `classifier-results/`: Presumptive match indicators and reaction metrics (Phase 3).
- `evidence-package/`: Cryptographic envelope summary, QR display, and PDF export (Phase 4).
